  > A modern Formula 1 themed web application showcasing racing excitement with Vue 3

  ## ✨ Features

  🏆 **Driver Profiles** - Meet your favorite F1 drivers with detailed stats
  🏁 **Team Overview** - Explore team histories and championship records
  🗺️ **Circuit Guide** - Interactive world map of F1 racing circuits
  📋 **Rules & Regulations** - Understanding F1 sporting regulations made easy
  📚 **Historical Timeline** - Journey through F1's legendary moments

  ## 🛠️ Tech Stack

  | Technology | Purpose | Why? |
  |------------|---------|------|
  | **Vue 3** | Frontend Framework | Modern, reactive, and performant |
  | **Vite** | Build Tool | Lightning-fast development experience |
  | **Tailwind CSS** | Styling | Utility-first for rapid UI development |
  | **Vue Router** | Navigation | Smooth single-page application routing |

  ## 🚀 Quick Start

  ### Prerequisites
  - Node.js 16+
  - pnpm (recommended package manager)

  ### Installation & Setup

  ```bash
  # Clone the repository
  git clone https://github.com/Selene-ovo/F1_Demo_Web_Page.git

  # Navigate to project directory
  cd F1_Demo_Web_Page/emotion_vue

  # Install dependencies
  pnpm install

  # Start development server
  pnpm dev

  # Build for production
  pnpm build

  📁 Project Architecture

  emotion_vue/
  ├── 📦 src/
  │   ├── 🎭 components/
  │   │   ├── pages/      # Main page components
  │   │   ├── ui/         # Reusable UI components  
  │   │   └── common/     # Shared layout components
  │   ├── 🎨 assets/
  │   │   ├── images/     # Static images & icons
  │   │   ├── music/      # Audio assets
  │   │   └── css/        # Global stylesheets
  │   ├── 🛣️ router/       # Vue Router configuration
  │   └── 📄 views/       # Top-level view components
  ├── 🔧 public/          # Static public assets
  └── ⚙️ config files     # Vite, ESLint, etc.
